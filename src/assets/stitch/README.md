# Stitch reference assets

Downloaded from the image URLs in the user-provided `stitch_spanda_dat_hero_ui.zip` (`code.html`). These are source assets; Astro generates optimized WebP variants at build time.

- `logo.png`: Spanda DAT wordmark
- `make-in-india.png`: Make in India emblem
- `manikin.png`: front manikin scene for the overview
- `group-learning.png`: instructor-led group training scene
- `listening-options.png`: speaker and individual receiver learning comparison
- `live-patient.png`: live patient auscultation scene

The source export includes illustrative clinical scenes. Higher-resolution source images can replace these files without changing the slide components. Keep descriptive filenames and update the slide data when replacing an image with a different subject.
