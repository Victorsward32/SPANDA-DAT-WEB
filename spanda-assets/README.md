# Spanda assets

Curated latest product images with simple, stable file names. Product PNGs have transparent backgrounds and soft contact shadows. Brochure pages retain their original page backgrounds. Original source files remain in the project assets folder.

## Folder structure

- `manikin/spanda-dat/`: front, back, left, right; smoothed body fabric.
- `scopes/`: DATS Scope R with the updated blue-and-green Spanda “Auscultation Redefined” chestpiece.
- `stethoscopes/`: Spanda Elite (with display), Spanda Pro (without display), and the earlier digital stethoscope render.
- `receivers/`: latest Spanda receiver with the shorter top tip.
- `other-products/`: speaker, router, seven-port USB hub.
- `brochures/spanda-dat/`: two original brochure pages.
- `learning/`: supplied Group Learning, Immersive Learning, and Live Patient Auscultation hero images, preserved as original PNGs.
- `manifest.json`: image paths, dimensions, alpha-channel information, and original source paths.

Left and right manikin views refer to the manikin’s anatomical sides. Product renders were edited/generated with built-in imagegen and can differ from reference photographs. Some transparent edges, particularly on the white router, retain visible residue on dark backgrounds.

Use these PNGs directly and preserve their alpha channels when exporting. Superseded versions, reference photos, prompts, and older ZIPs are excluded from this curated folder and remain available in the original assets folder.
